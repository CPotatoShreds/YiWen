# 数据库备份与恢复（P0.5）

## 备份策略

- 工具：`pg_dump -Fc`（自定义压缩格式，支持并行恢复与选择性恢复）；
- **服务器**：每日一次（cron 调用 `scripts/backup_db.sh`，脚本通过 `docker exec` 直连生产库容器），本地滚动保留 7 天（`PG_KEEP_DAYS` 可调）；
- **本机副本**：定时把服务器最新备份拉回自己的电脑（`scripts/pull_backup.sh`），本地滚动保留 30 份——这是"异地"的最简形式，不做对象存储。

## 服务器配置（腾讯云 CVM，2026-09-15 定案）

在服务器 `~/ynfight` 目录下配置 cron（`crontab -e`）：

```cron
# 每天 03:30 备份 PostgreSQL（日志滚动在 /var/log）
30 3 * * * cd ~/ynfight && ./scripts/backup_db.sh backups >> /var/log/ynfight_backup.log 2>&1
# 每周一 04:00 恢复演练到临时库后自动清理
0 4 * * 1 cd ~/ynfight && ./scripts/restore_db.sh "$(ls -t backups/*.dump | head -1)" ynfight_restore && docker exec ynfight-postgres psql -U ynfight -d postgres -c 'DROP DATABASE ynfight_restore' >> /var/log/ynfight_backup.log 2>&1
```

另需备份**应用数据卷**（含 SECRET_KEY、LLM 方案加解密密钥、日志）：

```bash
docker run --rm -v ynfight_appdata:/appdata -v "$PWD":/backup alpine tar czf /backup/appdata.tar.gz -C /appdata .
```

> SECRET_KEY 与 LLM 方案密钥换新会导致已签发 JWT 失效、既有密文不可解——迁移机器时这两个文件必须带走。

## 拉回本机（异地副本）

在**本机**（自己的电脑）执行：

```bash
SERVER=user@server-ip ./scripts/pull_backup.sh          # 拉取最新备份到 ./backups（保留最近 30 份）
```

定时：Windows 用「任务计划程序」建每日任务（程序 `C:\Program Files\Git\bin\bash.exe`，参数参考
`-lc "cd /d/vsProjects/ynfight && SERVER=user@server-ip ./scripts/pull_backup.sh"`），
或直接在 WSL/cron 环境里加一行 `0 9 * * * cd ~/ynfight && SERVER=user@server-ip ./scripts/pull_backup.sh`。

## 日常备份

```bash
./scripts/backup_db.sh backups        # 服务器：本机落盘（7 天滚动），cron 已自动化
SERVER=user@host ./scripts/pull_backup.sh   # 本机：从服务器拉取（30 份滚动）
```

## 恢复

```bash
./scripts/restore_db.sh backups/ynfight_20260912_033000.dump ynfight        # 覆盖恢复主库
./scripts/restore_db.sh backups/ynfight_20260912_033000.dump ynfight_restore  # 恢复到临时库（推荐先演练）
```

## 恢复演练（每季度一次 + 每周一自动演练，完成后在本文件追加记录）

1. 取最近一份 `.dump`；
2. 恢复到临时库：`./scripts/restore_db.sh <备份文件> ynfight_restore`；
3. 对账抽查：`docker exec ynfight-postgres psql -U ynfight -d ynfight_restore -c "SELECT count(*) FROM users;"` 等，与主库比对；
4. 清理临时库：`docker exec ynfight-postgres psql -U ynfight -d postgres -c 'DROP DATABASE ynfight_restore'`。
